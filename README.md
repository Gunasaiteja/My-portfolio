# Netflix-Style Portfolio

A Netflix-inspired personal portfolio for **Guna Sai Teja K**, an aspiring software engineer. Instead of a plain resume, my work is laid out as rows you can browse: projects, experience, job simulations, skills and education. Click any card to see the details.

**Live site:** https://YOUR-USERNAME.github.io/netflix-portfolio/

## Features

- Netflix-style hero banner with a featured project
- Horizontally scrolling rows with arrow buttons and swipe support
- Click a card to open a details popup
- Responsive layout for desktop and mobile
- Keyboard accessible, with reduced-motion support
- Pure HTML, CSS and JavaScript. No frameworks, no build step

## Run locally

```bash
git clone https://github.com/YOUR-USERNAME/netflix-portfolio.git
cd netflix-portfolio
```

Open `index.html` in your browser. That's it.

## Customize

Open `index.html` and edit the script at the bottom:

- `LINKS`: add your LinkedIn, GitHub and email URLs
- `LIVE`: add live demo URLs, for example your City Care link on Render
- `DATA`: add, remove or edit cards in any row

## Deploy on GitHub Pages

1. Push this folder to a new repository named `netflix-portfolio`.
2. Go to **Settings, then Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then save.
4. Your site goes live at `https://YOUR-USERNAME.github.io/netflix-portfolio/` within a minute or two.

## Push to GitHub
